# The Oracle Runbook - Cloud Lab 1

## Oracle AI Database 26ai on OCI

> Hands-on lab work with **Oracle AI Database 26ai** using **Autonomous AI Database Serverless** on Oracle Cloud Infrastructure.

This repository documents the SQL and validation steps I used while provisioning the database, confirming the running environment, working with relational objects in Database Actions, and testing native vector capabilities.

## What I built

The lab database was provisioned as an Autonomous AI Database Serverless instance using the Transaction Processing workload.

After the database became available, I opened Database Actions and validated the database from SQL rather than relying only on the OCI console. I then created a small relational activity table and used it to record the lab steps.

The final section uses the native `VECTOR` datatype. The vectors in this repository are intentionally small, manually defined three-dimensional values. They are used only to make vector storage and distance calculation easy to understand. They are **not embeddings generated by an AI model**.

## Key validation result

The vector query compares each stored vector with the reference vector:

```text
[1,0,0]
```

Using the `COSINE` metric, the test returned:

| Item | Cosine distance |
| --- | ---: |
| Oracle Database Administration | 0 |
| RMAN Backup and Recovery | 0.006116 |
| Data Guard High Availability | 0.036913 |
| Linux System Administration | 1 |

The exact match returned a distance of zero. The other manually selected vectors were ordered by their calculated cosine distance.
